Key Controls & Segregation of Duties

All controls listed below are enforced at the API / service layer — not just the UI. They cannot be bypassed by direct API calls, Postman, or any other method.

SoD CONTROL 1
No Self-Authorisation
The user who captured (dealer_id) cannot be the user who authorises. Checked on every POST /authorise call. Returns HTTP 403 ERR_SOD_VIOLATION. Attempt logged permanently.
DEALER → cannot authorise own deals
SoD CONTROL 2
Dealer Cannot Value
POST /valuation/run returns HTTP 403 for ROLE_DEALER. Dealers cannot see mark-to-market valuations they could use to manipulate book P&L.
MIDDLE OFFICE only runs valuations
SoD CONTROL 3
Dealer Cannot Override Market Data
Market data overrides require ROLE_MIDDLE_OFFICE + secondary approval. No dealer can manipulate the prices used to challenge their own deal rates.
MIDDLE OFFICE dual-approval only
PRE-DEAL CONTROL
Synchronous Limit Check
Every deal submission triggers a simultaneous check of all applicable limits before the deal is saved. HARD breach → HTTP 422, deal NOT persisted. Cannot be bypassed.
Runs on 100% of deal submissions
PRE-DEAL CONTROL
Off-Market Rate Challenge
Rate deviation >10bp from live market data requires a written justification before deal can proceed. Justification is stored in the deal record and audit trail permanently.
Configurable tolerance (default 10bp)
OPERATIONAL CONTROL
Dual Authorisation for Config Changes
Limit changes, system parameter changes, and market data overrides all require a second authoriser different from the submitter. Changes stay PENDING until approved.
All system configuration changes
OPERATIONAL CONTROL
Confirmation Mismatch Blocks EOD
Any unresolved confirmation mismatch (rate, amount, or date difference vs counterparty confirmation) is a blocking item on the day-end close checklist. Cannot roll date with open mismatches.
Back Office must resolve same day
OPERATIONAL CONTROL
Aged Nostro Breaks Escalate Automatically
Breaks unresolved for >3 days auto-escalate to Treasurer and become blocking on the day-end checklist. >2 days: escalate to BO manager. Today: investigate same-day.
Ageing thresholds configurable
AUDIT CONTROL
Immutable Audit Trail — 7 Years
Every action (deal event, config change, login, failed attempt, SoD violation) is recorded with user, timestamp, IP, session ID, and before/after values. Cannot be deleted or modified.
INTERNAL AUDIT has full 7yr read access
AUDIT CONTROL
SoD Exceptions Permanently Visible
Any overridden toxic role combination (e.g. Treasurer + Dealer on same entity) is flagged as a Standing Control Exception and permanently visible to Internal Audit — cannot be hidden.
Visible to INTERNAL AUDIT always
REGULATORY CONTROL
CBK NOP Daily Return
End-of-day NOP is automatically computed from all exposure sources (FX deals + nostro + FCY investments + accruals) and submitted to CBK by 17:00. Missed submissions flagged.
Due daily by 17:00 EAT
REGULATORY CONTROL
LCR/NSFR Monitoring
Liquidity Coverage Ratio and Net Stable Funding Ratio computed daily. Alert when approaching regulatory minimum (100%) or internal buffer (125%). Included in CBK monthly prudential return.
CBK minimum: 100%
