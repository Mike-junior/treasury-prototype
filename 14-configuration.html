System Parameters
Core operational settings · Grey-out = locked by compliance · All changes logged to immutable audit trail
Four-Eyes Authorisation LOCKED
Every deal above KES 1M requires a second authoriser who did not capture the deal. Enforced at the API layer via SoD validator on every authorise call. Cannot be disabled.
Off-Market Rate Challenge — Tolerance: 10 bps
Deals where the captured rate deviates beyond this threshold from live market data trigger a mandatory justification box. Justification is recorded in the audit trail.
Real-Time Limit Checking
Pre-deal limit check runs synchronously before every deal submission. HARD breach → HTTP 422 blocks deal. WARNING → deal proceeds with alert. APPROVAL → deal pauses awaiting approver sign-off.
MFA Enforcement (Authoriser & Above)
TOTP authenticator required at login for ROLE_AUTHORISER, ROLE_TREASURER, ROLE_MIDDLE_OFFICE, ROLE_TENANT_ADMIN. Cannot be disabled for Authoriser roles per FR-02.2.
Scheduled Auto Day-End — Time: 17:30 EAT
If the Treasurer hasn't manually started day-end by this time, the system auto-initiates the EOD checklist. Disabling means day-end must always be started manually.
SWIFT STP Auto-Match on Confirmation Receipt
On receipt of MT300/MT320/MT910, the system auto-attempts to match against open TMS deals within configured tolerances. Unmatched items go to the Confirmation Matching queue.
User Auto-Suspend — Inactivity Period: 90 days
Accounts not logged in for this period are automatically suspended. Alert sent 10 days before. Reactivation requires Admin approval.
Audit Trail Retention — 7 Years LOCKED — IMMUTABLE
All system events are retained for exactly 7 years and cannot be deleted or modified. Required by FR-22. This parameter cannot be reduced or disabled under any circumstances.
